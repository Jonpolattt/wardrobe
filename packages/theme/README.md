# @wardrobe/theme

Plain brand, palette, surface, spacing, and radius tokens for web and native consumers. No React, DOM, native runtime, or secret configuration dependencies.

The web palette preserves the values from apps/web/tailwind.config.ts. Numeric spacing mirrors the existing Tailwind spacing scale; semantic native surfaces follow existing web CSS roles. Existing web CSS remains app-specific.

Build with the workspace TypeScript 5.9.3 tool before consuming the compiled CommonJS/declarations exports.
